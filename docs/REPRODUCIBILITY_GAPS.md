# 重建边界与已知缺口

本仓库提供已验证的过程、源码和版本记录，使后续复现可定位到具体层；不宣传为任意手机的一键安装器。

1. **设备相关输入**：宿主内核的ashmem/KGSL/dma_heap/视频节点、SELinux容器策略及同ROM厂商库必须自行取得。节点编号不能照抄。
2. **厂商二进制不分发**：图形/Codec私有依赖的名称和当前哈希在artifacts中；符号依赖仍需按自己的ROM用readelf和加载日志检查。
3. **历史辅助二进制**：部分init/FD wrapper、Codec私有platform兼容库/插件stub在长期工作目录中以编译产物存在。能找到的源码已收集；未找到或未能建立精确来源的项目不能声称可从本仓库单独按位重建。不能用替换未知ABI、假ioctl或开放宿主权限来填这个缺口。
4. **构建范围**：AOSP记录覆盖已知补丁目标与HEAD差异，不是整个repo树的未跟踪文件审计。Mesa以原归档比较提取修改文件，并另外保存新增bridge源。
5. **部署状态**：真机镜像经历增量安装和数据使用，不能等同于干净release。整套从零全编译和新镜像端到端部署尚待独立验收。
6. **网络根治**：broker共享socket UID2000；原生应用UID与宿主BPF的隔离仍未解决。
7. **适用范围**：Gralloc二进制修补锁定一个输入哈希；更多分辨率/格式、其他ROM/设备和所有应用的Surface编码仍需验证。
8. **业务验收**：游戏只到登录入口，脚本到配置/截图/停止；登录、对战、自动操作和长时耐久没有完成。
9. **安全边界**：full privileges、应用数据隔离关闭、libselinux容器兼容、指定设备暴露和socket身份共享都是需要保留的限制说明。
