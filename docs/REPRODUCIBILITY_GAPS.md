# 重建边界与已知缺口

本仓库区分[第一部分核心复现](FULL_PROCESS.md)与[第二部分补充](PART2_SUPPLEMENT.md)。本仓库提供已验证的过程、源码和版本记录，使后续复现可定位到具体层；不宣传为任意手机的一键安装器。

1. **设备相关输入**：宿主内核的ashmem/KGSL/dma_heap/视频节点、SELinux容器策略及同ROM厂商库必须自行取得。节点编号不能照抄。
2. **厂商二进制的兼容范围**：[2026-11-28 Release](PREBUILT_RELEASES.md)已提供当前机型/ROM的完整静态镜像和逐文件哈希，降低缺失历史产物导致的复现困难。其它ROM的符号依赖仍需用readelf和加载日志检查；分发二进制不等于提供其源码或实现跨设备兼容。
3. **历史辅助二进制**：部分init/FD wrapper、Codec私有platform兼容库/插件stub在长期工作目录中以编译产物存在。能找到的源码已收集；未找到或未能建立精确来源的项目不能声称可从本仓库单独按位重建。第二部分新增可追溯cap-init，Next分支不再执行历史FD wrapper；Codec私有兼容库等其余缺口仍在。不能用替换未知ABI、假ioctl或开放宿主权限来填这个缺口。
4. **构建范围**：AOSP记录覆盖已知补丁目标与HEAD差异，不是整个repo树的未跟踪文件审计。Mesa以原归档比较提取修改文件，并另外保存新增bridge源。
5. **部署与构建状态**：原真机工作镜像有增量安装和应用数据，不直接分发。11-28从静态系统新建12 GiB ext4、恢复xattr、验证空数据，并在字节相同的副本上完成首次启动与模块冷启动；发布文件保持未启动。11-24的独立部署见[历史报告](REPRODUCTION_20261124.md)。从空源码环境全编译仍待验收；历史Magisk输入是unofficial版本，尚无精确对应源码，不能冒充当前上游同版本APK。
6. **网络根治**：broker共享socket UID2000；原生应用UID与宿主BPF的隔离仍未解决。
7. **适用范围**：Gralloc二进制修补锁定一个输入哈希；更多分辨率/格式、其他ROM/设备和所有应用的Surface编码仍需验证。
8. **业务验收**：游戏只到登录入口，脚本到配置/截图/停止；登录、对战、自动操作和长时耐久没有完成。
9. **安全边界**：第一部分full权限为历史基线；第二部分arm使用nocaps加自定义init删除五项，仍保留36项且没有root UID映射，尚未逐项最小化。应用数据隔离关闭、libselinux容器兼容、指定设备暴露和socket身份共享仍是限制。
10. **补充范围**：Next1.5.3/LSPosed2.2.1已于11-25在repro增量复现，11-28又在空数据发布镜像副本上完成安装、冷启动、真实回调和system_server接入；stock scrcpy默认QTI编码及VAAPI实际窗口像素也通过。x86未复测，真实代理认证账号、Xposed业务hook、所有协议/格式和长期测试仍未验收。
